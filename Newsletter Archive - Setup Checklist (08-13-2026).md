Notes:
- Step 1: repo created, verified Public and empty. Key idea learned: the repo has two
  addresses. github.com/... shows the files as code. bereacollege-ie.github.io/... serves
  them as a website. Only the second one goes in an email. The github.io address does not
  exist until Pages is switched on in step 3.
- Between steps 1 and 2: the local folder was wired to the repo by hand (git init, remote
  set to origin). GitHub Desktop's "Publish repository" would have tried to create a second
  repo with the same name and failed.
